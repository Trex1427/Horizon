# Sprint Template

Use this template for each sprint.

## Objective

Describe the main business or technical goal of the sprint.

## Files concerned

List the files that will be created or modified.

## Plan before coding

- explain the approach
- identify the impacted files
- confirm the expected behavior
- mention any risks or constraints

## Implementation

Describe the concrete steps of the implementation.

## Tests

List the functional and UI tests to run.

## Limits

Note what is intentionally left out for now.
