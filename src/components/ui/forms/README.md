# Forms

Role:
- Provides reusable data-entry controls.

Components present:
- Input
- SearchInput
- CurrencyInput
- Textarea
- Checkbox
- Switch
- Select
- DatePicker

When to use:
- Use for all user input surfaces in pages and dialogs.

Rules:
- Keep controls accessible and consistent.
- Do not format or compute business values here.
- Tout nouveau composant UI doit appartenir a une famille.
