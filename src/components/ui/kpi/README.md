# KPI

Role:
- Provides metrics-focused components for quick status reading.

Components present:
- AppKpiGrid
- CompactKpiGrid
- AppStatCard
- KpiCard

When to use:
- Use for top-of-screen metrics and compact numeric summaries.

Rules:
- Keep labels short and values prominent.
- Avoid business calculations inside KPI components.
- Tout nouveau composant UI doit appartenir a une famille.
