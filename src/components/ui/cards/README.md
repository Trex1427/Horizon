# Cards

Role:
- Provides reusable information cards for summaries and detail blocks.

Components present:
- Card
- SummaryCard
- SectionCard
- InfoCard
- AppCard

When to use:
- Use for grouped content with consistent elevation and spacing.

Rules:
- Cards must stay presentational.
- Reuse existing card variants before creating a new one.
- Tout nouveau composant UI doit appartenir a une famille.
