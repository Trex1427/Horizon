# Charts

Role:
- Renders visual data primitives without business calculations.

Components present:
- LineChart
- DonutChart
- Sparkline
- ProgressBar
- Badge

When to use:
- Use for trend, distribution, and progression visuals.

Rules:
- Charts consume prepared data only.
- Keep aria labels and reduced motion support.
- Tout nouveau composant UI doit appartenir a une famille.
