# Toolbar

Role:
- Standardizes search, secondary tools, and compact toolbar composition.

Components present:
- ToolbarSearchShell
- AppSearchBar
- AppSecondaryToolsButton
- AppToolbarSearchField
- CompactToolbarLayout
- AppToolbar

When to use:
- Use for list and collection control surfaces (search/filter/sort/actions).

Rules:
- Keep interaction patterns stable across pages.
- Avoid page-specific business behavior in toolbar primitives.
- Tout nouveau composant UI doit appartenir a une famille.
