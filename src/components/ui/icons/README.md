# Icons

Role:
- Hosts icon wrappers and iconography conventions.

Components present:
- MuiIcons (bridge des icones MUI via famille officielle).

When to use:
- Use for shared icon policies and reusable icon wrappers.

Rules:
- Keep icon sizing and alignment consistent.
- Avoid page-local icon conventions.
- Tout nouveau composant UI doit appartenir a une famille.
