# Layout

Role:
- Organizes page structure, sections, and responsive composition.

Components present:
- PageLayout
- PageHeader
- Section
- Grid
- Container
- AppPage
- AppHeader
- AppSection

When to use:
- Use for structural composition of screens and content blocks.

Rules:
- Keep layout components presentation-only.
- Do not embed business calculations.
- Tout nouveau composant UI doit appartenir a une famille.
