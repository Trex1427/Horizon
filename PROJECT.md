# Project Overview

This project is a personal budget management application built with React, Vite, Material UI, Firebase, and Firestore.

## Goals

- Track personal transactions
- Provide a clear financial dashboard
- Support CRUD operations for transactions
- Keep the architecture modular and evolutive

## Current Status

- Transactions creation, editing, and deletion are implemented
- Firestore is used for real-time updates
- A dashboard layer is being introduced to separate business logic from UI

## Tech Stack

- React
- Vite
- Material UI
- Firebase
- Firestore
- JavaScript

## Notes

The project is being evolved step by step with a strong focus on maintainability, clarity, and future extensibility.
