## Statut du document
Ce glossaire fixe le vocabulaire court officiel de la Constitution Horizon.

## Champ d'application
Ce document definit les termes fonctionnels et d'interface utilises dans les autres documents Horizon.

## Glossaire
- Carte : unite compacte de scan rapide.
- Drawer : panneau contextuel de detail, ouvert sans changer de page par defaut.
- KPI : indicateur cle visible en priorite.
- Toolbar : zone de controle contenant recherche, filtres, tri et actions.
- Pilotage : capacite a comprendre une situation et agir vite.
- Reconciliation : rapprochement entre donnees attendues et donnees reelles.
- Prevision : projection d'un etat financier futur a partir des donnees disponibles.
- Referentiel : ensemble de valeurs de reference reutilisables dans toute l'application.
- Objectif : cible suivie dans le temps avec un statut de progression.
- Workflow : sequence d'etapes necessaires pour accomplir une action.
- Action principale : action prioritaire de l'ecran ou du parcours.
- Action secondaire : action utile mais non prioritaire dans le contexte courant.
- Empty State : etat d'ecran sans donnees utiles a afficher.
- Section : bloc thematique regroupant des informations ou actions proches.
- Statut : qualification metier d'un element a un instant donne.
- Etat : condition d'affichage ou de fonctionnement d'un composant ou d'un ecran.
- Timeline : representation chronologique d'evenements ou d'etapes.
